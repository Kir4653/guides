WhiteHell Guides — minimal style pack

Стиль переработан в тёмный минималистичный формат: крупный hero-блок, glass-карточки, pill-навигация, аккуратные таблицы команд и FAQ.

Кланы не включены, потому что механика в разработке.

Как поставить:
1. Замени старые HTML-файлы на файлы из архива.
2. Создай/оставь папку images рядом с HTML.
3. Добавь скриншоты с названиями из SCREENSHOTS_PLAN.md.
