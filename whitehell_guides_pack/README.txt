Готовый черновик гайдов WhiteHell.

Что внутри:
- HTML-страницы для команд, FAQ, старта, квестов, магии, прокачки, артефактов, лучника, призывателя, спавнеров, миров, наград и экономики.
- SCREENSHOTS_PLAN.md — список скриншотов, которые лучше сделать в игре.

Важно:
- Кланы не добавлены, потому что механика в разработке.
- В HTML стоят пути images/*.png. Когда сделаешь скрины, создай папку images рядом с HTML и положи файлы с такими названиями.
- Страницы можно залить в GitHub Pages вместо старых или использовать как основу для переноса текста.
